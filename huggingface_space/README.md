# Groq Chatbot

A Streamlit chatbot that uses the Groq API. It runs in the browser with [stlite](https://github.com/whitphx/stlite), so this Space is a static Space with a single `index.html`.

Enter your own Groq API key in the sidebar to chat. The key is not stored anywhere.
